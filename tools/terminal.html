# linux & windows terminal

Practise real commands safely. Switch between a Linux (bash) shell and a Windows (CMD) prompt, each with its own files, users and processes. Type a command from the other system and it will tell you the equivalent. Everything is simulated in your browser — nothing touches a real computer.
